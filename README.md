# forKARATE

空手道場の運営に役立つ無料ツール集です。
インストール不要・ブラウザで開くだけで使えて、**入力した情報はすべて端末内にのみ保存されます**。

## ツール

- **[練習日程表メーカー](https://kreatio-works.github.io/forKARATE/calendar-maker/)** — 月間練習日程表を作って、A4横1枚のExcelファイル（.xlsx）として出力（[説明](calendar-maker/README.md)）
