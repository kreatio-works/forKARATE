# 練習日程表メーカー

道場・教室などの月間練習日程表を作って、**A4横1枚のExcelファイル（.xlsx）** としてダウンロードできるツールです。
インストール不要・ブラウザで開くだけで使えます。

**団体名・道場名・練習パターンなどの情報は、お使いの端末（ブラウザ）内にのみ保存されます。サーバーには一切送信されません**（ExcelJS使用）。

## 使う

- https://kreatio-works.github.io/forKARATE/calendar-maker/

## できること

- **定例パターンから自動生成** — 曜日ごとの練習時間・場所を登録すると、1か月分の日程表を自動で組み立て
- **日ごとの編集** — 行をタップして時間変更・休み表示・黄色の強調・行の削除
- **行の追加** — 合同練習・大会・休みなどの結合行（全道場まとめて1行）も追加可能
- **Excel出力** — セル結合・罫線・黄色塗り・赤字のお願い文つきで、A4横1枚に収まる印刷設定済みの .xlsx を生成
- **バックアップ・引き継ぎ** — 設定と編集内容をJSONファイルに書き出し／読み込み（端末の変更・担当交代に）

編集内容は月ごとにブラウザへ自動保存されます。PC・Mac・iPhone・iPadのブラウザで動作します。
